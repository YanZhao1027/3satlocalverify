# 科研状态校准：离论文通用运行时间优势还有多远？

**时间：2026-10-28（新加坡）** · **实验机：Ubuntu / 约 109 GiB RAM** · **相关源：** [原生叶节点实际执行报告](NATIVE_LEAF_TERMINAL_EXECUTION_20261028.md)、[复杂度与桶宽报告](COMPLEXITY_20261028.md)、[原版叶节点证明连接](NATIVE_LEAF_BRIDGE_20261028.md)。

## 结论

**形式化验证基础已经比较扎实；完整原版算法的非终止计算路径尚未独立执行，所以现在还不能用本机数据证明论文所声称的通用时间优势。** 这不是一个接近 100% 的线性进度条：外围定理越多，并不必然意味着核心可执行化剩余工作越少。

### 三种必须区分的目标

| 目标 | 当前证据 | 尚缺的关键步骤 |
| --- | --- | --- |
| 复核 OpenAI 的数学证明及资源上界 | 原版定理在 Lean 4.34.1 和 Comparator 通过；本项目检查了原生叶节点资源契约、具体预算可行性和标准公理依赖 | 这些是证明检查，不是实际程序的计时记录 |
| 本地运行论文真正节省计算的核心路径 | 独立执行了原版终止分支的位指令，与完整原版命令的同分支轨迹等价性已由 Lean 检查；源级步骤与栈位数实际记录 | **让真实、有效、非空且无空子句的 CNF 进入 `NativeLeafProgram.command` 的非终止高查询路径**，不能用 `skip` 替换被执行分支、也不能预置答案 |
| 在非特制输入上建立端到端时间优势 | 暂无这样的对照证据；局部 Hermite/CRT、桶消元速度和终止路径步骤不能代表全算法 | 真正构造并运行非终止程序、端到端资源计量、和完成相同精确 #SAT 工作的基线比较 |

## 必须正视的技术缺口

1. **源级非计算性：** 上游 `SqrtLogSpace/HighQueryProgram.lean` 置于 `noncomputable section`，直接 `#eval NativeLeafProgram.command 2` 报 `dependsOnNoncomputable`。`noncomputable` 标签不是对其所有子过程不可构造的证明；应识别第一处真正影响程序数据的不可计算依赖，并评估可计算替代及语义保持。
2. **不能把解释器内存耗尽当作算法的内在空间：** 使用 Lean 依赖类型 `TM2.Cfg` 直接解释小终止路径的实验曾在 55 秒超时，进程最大 RSS 约 80 GiB。这是一次失败的运行尝试，不是“论文图灵机需要 80 GiB”的证据。优先评估紧凑指令表、共享调用以及数组式栈状态，使用已有的编译与轨迹定理作为核对基准。
3. **固定程序的预处理/常数成本：** 上游 `SqrtLogSpace/FiniteFallback.lean` 使用输入前选定的有限控制/表。必须记录这些对象的真实构造、编码及存储成本；不能把尚未构造的天文规模表当作免费常数。
4. **不能混淆任务与指标：** 精确 #SAT 不能直接和仅找一个满足赋值的 SAT 判定耗时混比。源级 `BitProgram` 步数、TM2 块步骤、原生图灵机磁带微步骤、访问过的磁带单元、峰值栈数据位、进程 RAM 和墙钟时间分别统计。形式化复杂度上界、实测速度和实际加速是不同结论。
5. **普通桶消元不是完整原版算法：** 已证明的缓存表行数上界为 `t·2^w`（最大桶宽 `w`）；三文字 CNF 存在使任何第一步桶宽均为 `n` 的结构族。它阻断了“仅优化消元顺序即可普遍加速”的简单推断，但**不构成任意 SAT 算法的指数时间下界**。

## 下一实验：最小非终止执行证据（最高优先级）

- 选择一个真实、物理编码满足上游 `LeafReady` 的 **3-SAT 非终止输入**（至少一个非空子句且没有空子句），明确阈值、上下文寄存栈和预期 #SAT 参考答案。
- 对原版 `NativeLeafDispatch`、`NativeLeafExecution`、`NativeLeafProgram`、`HighQueryProgram` 分层，精确定位阻碍 Lean 代码生成的首个依赖；禁止将被执行的查询/累加代码替换为 `skip`。
- 若需建立可执行替代实现，必须证明程序轨迹等价或足够强的状态不变量，并对实际采用的实例提供核对；候选程序的“答案碰巧相同”不等于等价。
- 从真正执行的位指令记录每类 opcode、步骤、所有前缀的栈位和最大单栈长度；对 TM2/原生编译只能在已有定理许可范围内提出上界，不能在未执行时写成实测。
- 在相同任务上记录输入处理、准备、查询、重构和输出。独立穷举参考用于小样例正确性核对；基线要是完整且匹配的精确计数程序。保存原始日志和失败情况；大对象使用时间与内存上限。

**短期成功的定义：** 第一个可公开重放的、经过 Lean 语义/轨迹核查的非终止路径执行，并报告真实资源数据，即便它暂时比基线慢。**长期成功的定义：** 在完整执行路径上，找到可重复的、被明确归因到论文机制的净节省，并进一步审查最坏情况上界。不能承诺某个变量数一定跑得快，更不能用有限实验单独证明 `2^{o(n)}` 最坏情况。

## 对设备与研究前景的判断

当前设备的内存与 CPU 已足以完成大量 Lean 检查和真实源级终止路径运行；没有证据保证它可以在现实预算内生成/运行原版完整固定程序。下一步技术方向明确，**实际通用加速是否能在个人电脑上展示仍有关键不确定性**。值得追求可重放的“第一个非终止原版计算”，而不是仅把低宽度样例做得更大。

**研究诚信：** 本报告的已验证事项来自已保存的代码、报告与复现脚本；计划中的实验不应被写成已完成。上游 OpenAI 形式化定理不等于我们已提取整个快速 SAT 求解器；任何包含预计算结果的“加速”都必须把预计算计入成本。
